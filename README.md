# 📊 Sales Analytics Dashboard — Business Intelligence (Power BI)

An **interactive multi-page Power BI dashboard** that tracks revenue trends, regional KPIs and
sales performance across **5+ integrated business data sources** — turning raw spreadsheets into
executive-ready insights.

> Built by [Bonugu Sai Kiran Manideep](https://manideep-2006.github.io/my-portfolio/) ·
> B.Tech CSE (Data Science), VIIT Visakhapatnam

---

## 🎯 What it delivers

- 📈 **Revenue trends** — month-over-month and year-over-year comparisons
- 🗺️ **Regional KPIs** — sales performance by territory
- 🛒 **Product & category analysis** — top sellers, funnel visuals
- 🎛️ **Dynamic KPI cards** — period-over-period deltas for executive decisions
- ⚡ Cut manual reporting effort by **~40%** while improving accuracy & consistency

## 🧰 Built With

| Tool | Used for |
|---|---|
| **Power BI Desktop** | Dashboard design, visuals, interactions |
| **Power Query** | Data cleaning & transformation across 5+ sources |
| **DAX** | Custom measures, KPIs, period-over-period calculations |
| **Excel** | Source data preparation |
